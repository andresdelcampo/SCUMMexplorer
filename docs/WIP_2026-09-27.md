## Verb-area images, reached states and unavoidable entry states, done

The 16 first-stored-image rooms were traced through every decoded object reference. Three general rules came out of it:

1. **Interface images.** Images that `verbOps … image` shows in the verb area are not room artwork. This covers literal operands (Room 01's distaff pieces 100–151) and every literal assigned to a global-variable operand (`var[0x068]`, set by each object's verb 0x39 and shown in the close-up box by script 008 +0x002D). They are never used in estimates.
2. **Reached `setState`.** An object whose state reached code set on this visit no longer gets the first-stored-image guess. A draw batch can still show it.
3. **Unavoidable entry `setState`.** A literal `setState` that every path through the entry script must pass applies before the stored-image guess (Room 18's 373, entry +0x00DA).

First-stored-image rooms: 24 → 4 (01, 04, 20, 30). Tests: 111/111. Audit: 0 gaps. Room 58 still has no evidence. See [validation](../.verification/fallback-evidence/validation.md).
